# Глубина 🌊

**[Смотреть сайт →](https://abelaia.github.io/deep-dive/)**

Погружение от поверхности океана до дна Марианской впадины, 10 935 метров.
Вся вода рисуется одним WebGL-шейдером: волны и солнце, блики и лучи под водой, гаснущий свет, морской снег и светящиеся организмы на глубине. Если провести рядом курсором или пальцем, они разгораются.

## Стек

- **React 19 + TypeScript + Vite**
- **WebGL (GLSL):** один полноэкранный фрагментный шейдер, без библиотек
- **Lenis:** плавный скролл, глубина считается из прогресса прокрутки
- **SCSS по БЭМ:** дизайн-токены, флюидная типографика без rem
- **Web Audio API:** синтезированный звук (прибой, подводный гул, кит, сонар, пузыри)

## Производительность

Один canvas и один вызов отрисовки на кадр. На телефоне шейдер рендерится в пониженном разрешении, а на скрытой вкладке не рисуется вовсе.

## Запуск

```bash
npm install
npm run dev
```
