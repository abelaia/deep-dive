# Глубина 🌊

**[Смотреть сайт →](https://abelaia.github.io/deep-dive/)**

Вы в кабине батискафа. Скролл — это спуск: от поверхности Тихого океана до дна Марианской впадины, 10 935 метров.
Океан виден только через иллюминатор, а всё остальное — приборная панель: бортовой журнал, циферблат глубины, сонар, ленточный высотомер.

## Что внутри

- **Предпогружная проверка вместо прелоадера.** Системы батискафа проверяются по очереди: «Балласт … OK», «Прожектор … OK».
- **Иллюминатор.** Металлический обод с заклёпками, блик на стекле. За ним небо и волны, блики солнца, стая рыб, черепаха, скат-манта, кит, акула, медузы, кальмары, рыбы-фонарики, сифонофоры, гребневики, осьминог Дамбо и дно впадины с морскими огурцами.
- **Ощущение спуска.** Взвесь в воде в два слоя с параллаксом проносится вверх тем быстрее, чем быстрее вы листаете. В темноте планктон вспыхивает следом за курсором.
- **Бортовой журнал.** Каждая зона — запись, которая печатается по буквам с мигающим курсором и щелчками клавиш.
- **Приборы.** Аналоговый циферблат со стрелкой, давление, температура воды, процент солнечного света, ленточный высотомер как в кабине самолёта.
- **Прожектор.** В полночной зоне курсор становится прожектором: в темноте прячутся удильщик, рыба-топорик, адский вампир и мешкорот. Сонар показывает, где их искать.
- **Спектр.** Вода съедает цвета: красный пропадает на 15 м, оранжевый на 30, жёлтый на 60.
- **Сюрприз на дне.** На 9 000 м по стеклу бегут трещины, кабина вздрагивает, приборы краснеют, включается тревога. Финал — «Аварийное всплытие».

## Стек

- **React 19 + TypeScript + Vite**
- **GSAP + ScrollTrigger:** вся история — один timeline, привязанный к скроллу
- **Lenis:** плавный скролл
- **SCSS по БЭМ:** дизайн-токены, миксины, флюидная типографика без rem
- **Canvas 2D:** стая рыб (boids с избеганием курсора), морской снег и пузыри, размер по иллюминатору через ResizeObserver
- **CSS mask:** прожектор проявляет существ через `mask-image` с координатами курсора внутри круга
- **Web Audio API:** весь звук синтезируется, без аудиофайлов

## Звук

Прибой, глухой подводный гул (фильтр опускается с глубиной от 1100 до 90 Гц), низкий эмбиент, песни кита, сонар с эхом,
скрип корпуса под давлением, треск стекла, сигнал тревоги и щелчки клавиш журнала.

## Структура

```
src/
├── content/        # зоны, существа, спектр, температуры и тексты интерфейса в JSON
├── models/         # TypeScript-типы
├── constants/      # конфиг, темы приборов, геометрия SVG и трещин, имена data-anim
├── hooks/          # useStory, useFlashlight, useCanvas, useTypewriter, useMissionClock, …
├── animation/      # scroll-timeline, intro, общее состояние истории
├── audio/          # синтезатор звука
├── lib/            # gsap, плавный скролл, курсор, bem-хелпер
├── components/     # Cockpit, Porthole, Log, Instruments, DepthTape, BootScreen, …
└── styles/         # _variables.scss (токены) и _mixins.scss
```
